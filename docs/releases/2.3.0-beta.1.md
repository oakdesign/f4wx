F4Wx 2.3.0-beta.1 — Custom Weather Editor
=======================================

This beta from the oakdesign fork adds a visual weather-map editor to F4Wx, built on the original project by syn111 (Ahmed).

Download `F4Wx-2.3.0-beta.1-windows-x64.zip`, extract it to a folder, and run `F4Wx.exe`. Select your theater, then choose **New Weather**, **Open fmap**, or **Edit Current**.

What's included
---------------

- Create a weather map without downloading GRIB data, load an existing version-8 fmap, or edit an independent copy of the current downloaded frame.
- Paint Sunny, Fair, Poor, and Inclement presets; edit temperature, pressure, visibility, clouds, fog height, and wind at ten altitude levels.
- Brush size and strength, soft edges for numeric fields, rectangle fill, whole-map fill, eyedropper, and cell inspection.
- Zoom, pan, grid overlay, undo/redo, and map-wide wind, stratus, and contrail settings.
- Export fmaps with validation and protected replacement of existing files.
- Double-buffered canvas rendering to prevent flashing during mouse movement.
- Portable thread shutdown for the VS2019 C++20 library and a fix for wind-preview hangs on small maps.

Testing and limitations
-----------------------

The release is built for Windows x64. Automated debug/release data tests and Win32 editor tests pass, including binary round trips, malformed-input rejection, undo/redo, wind-direction blending, and repeated brush redraws.

This is a beta: loading exported custom maps in Falcon BMS 4.38 still needs simulator validation. Editing supports one frame at a time; sequence editing and automatic weather evolution are not included. Imported fmaps must use version 8 and match the selected theater's dimensions. Fmaps do not identify their theater. Weather presets are authoring defaults rather than a meteorological simulation.

**Save As** produces a standalone fmap; place it in the campaign directory and load it manually in BMS. Read `README.md` for the editor controls. Map-wide wind is edited separately or explicitly derived from the 12000 ft wind layer. Beta releases do not appear in the application's stable-release update check.

Please report problems at https://github.com/oakdesign/f4wx/issues with the theater, steps to reproduce, and an example fmap when possible.
